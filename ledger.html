Zero Cube Pledge Ledger

An open, append-only blockchain of pledge fingerprints — check it yourself.

In one line

Every approved pledge's fingerprint, block by block — open for anyone to check, with no personal data.

Download chain.json

BlockDateEntriesMerkle rootPrevious block hashBlock hashSigned

Tap a block number to see its fingerprints. One block is added each night that has approvals. Block #0 is the genesis block (the start of the ledger).

What is in a block?
  • Block number and date / time (IST).
  • Pledge IDs and fingerprints (salted SHA-256): never names or other personal data.
  • Merkle root: one hash that summarises every fingerprint in the block.
  • Previous block hash: links this block to the one before, forming the chain.
  • Withdrawals recorded that day (old blocks are never edited).
  • Block hash and Zero Cube's digital signature (RSA-SHA256), checked against our published public key.
Who runs this ledger?

Zero Cube runs this as a permissioned blockchain: only Zero Cube adds blocks, and anyone can read and check them. The blocks are published in open files with public version history, which adds a second tamper-evident record. No third-party networks or fees are involved.
