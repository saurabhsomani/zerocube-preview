SROI — Social Return on Investment

How much social, environmental and economic value does a project create for every ₹1 spent? We help funders, NPOs and communities answer that with evidence.

In one line

SROI shows how much good each rupee does — so donors, companies and NPOs can see real change.

NPOs & SROI

Turning good work into measurable value

All NPOs are, at heart, doing work for society in line with the Sustainable Development Goals. SROI helps them present that work in a tangible, measurable form — so a donor understands how much social return their donation creates.

From story to value (illustrative)

  1. The story — a village learning centre helps 40 girls stay in school
  2. The outcomes — better learning, fewer dropouts, more confidence, time saved for families
  3. The evidence — attendance, learning checks, parent interviews, follow-up
  4. The value — outcomes valued with sourced proxies, adjusted for what would have happened anyway
  5. The ratio — e.g. ₹3.2 of social value for every ₹1 donated

Illustrative example only — not a real project or a Zero Cube result.

What the donor sees

  • The SDGs the project serves
  • Social value created per ₹1 donated, with a range
  • How the money was spent, against budget
  • Evidence: photos, data and dMRV where relevant
  • A transparent report that states assumptions and limits

What is SROI

Value you can see and defend

Social Return on Investment is a structured way to measure and value change. It asks the people affected what changed for them, measures those outcomes, values them using sourced financial proxies, and compares the total value with the investment.

The result is a ratio such as ₹3 of social value for every ₹1 invested, together with the evidence and assumptions behind it.

Impact map, stakeholder engagement, value map, SROI ratio and sensitivity analysis for CSR teams, foundations and NPOs.

CSR impact assessment

Independent assessment reports for the Board and annual CSR report, with SROI as one lens — including projects requiring assessment under CSR Rule 8(3).

Village & school SROI

SROI reports and dashboards included in Sponsor-a-Village and school programmes.

Our process

  1. Scope — purpose, boundaries, stakeholders
  2. Engage — hear from the people affected
  3. Map — inputs, activities, outputs, outcomes
  4. Evidence — field data plus dMRV and Impact Portal evidence
  5. Value — sourced financial proxies
  6. Adjust — deadweight, attribution, displacement, drop-off, sensitivity
  7. Report — a transparent report with the ratio and its limits

Sample report outline

What an SROI report contains
  1. Summary and SROI ratio (with range)
  2. Scope and stakeholders
  3. Theory of change and impact map
  4. Outcomes, indicators and evidence
  5. Financial proxies and sources
  6. Adjustments and sensitivity
  7. Calculation
  8. Limitations — what we did not claim
  9. Recommendations
  10. Annex: data, dMRV evidence, assumptions
Independence: Zero Cube never assesses a project it designed or implemented. SROI ratios are reported with their assumptions and are never presented as financial or investment returns.
